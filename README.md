# montfortf.github.io

Tempo — design system options for the Brite PSA application.

`index.html` is a single self-contained page: three complete design directions
(Boardroom, Daylight, Atmosphere), each with colour tokens, a type scale,
spacing/radius/elevation, and working components, in both light and dark.

Generated from the sources in the Certinia working directory
(`design-source/`, assembled by `build.py`). Edit there and rebuild rather
than editing `index.html` directly.
